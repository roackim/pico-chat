# pico_chat

**Local AI assistant in the command line** – a lightweight, extensible CLI tool that runs a local LLM with optional tool integration.

---

## Overview

`pico_chat` provides an interactive terminal interface to a local large language model (LLM). It is built for developers who want a fast, controllable AI assistant without a remote API. The core loop supports:
- Streaming LLM responses
- Tool execution via a sandboxed execution environment
- Persistent memory and conversation history
- Customizable system prompts and security policies

---

## Current Features

- **LLM agnostic**: Connect any model that follows the OpenAI‑compatible client.
- **Tool integration**: Declare and invoke tools (e.g., file I/O, web requests) from the conversation.
- **Memory persistence**: Automatic snapshots of conversation state for resumable sessions.
- **Secure sandbox**: Runtime permission model isolates tool execution.
- **TUI**: Terminal UI with scrollable history, cursor handling, and fuzzy navigation.
- **Input ergonomics**: Dynamic height, `Ctrl+W`, mouse wheel scrolling, and expandable thinking panels.
- **Cursor management**: Disabling/reenabling the cursor to avoid flicker in large terminals.
- **Command handling**: Core commands (`/help`, `/clear`, `/exit`, `/status`, `/stop`, `/retry`) fully functional.
- **Error handling**: Tool call failures are reported back to the LLM for graceful recovery.

## Quick Start

```bash
# Start the CLI assistant
python pico_chat/main.py
```

Typical session:

```
> Hello, I'm pico. How can I help you today?
> Write a short Python script that reads a CSV file and prints the first row.
[tool: python] executing: 
import csv, sys; print(list(csv.reader(sys.stdin))[0])
> Done.
> Show me the code you just wrote.
[tool: python] executing: 
...
```

For a full list of commands, type `help` inside the terminal.

## Development

- Run tests: `pixi run tests` or `pytest tests/`
- Add new tools: Implement a class in `pico_chat/harness/tools.py` and register it in `tool_wrappers.py`.
- UI extensions: Modify files under `pico_chat/ui/` following the existing TUI component patterns.
